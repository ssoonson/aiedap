# AIEDAP 모듈5 연수 웹앱 — 설정 및 사용 안내

PPT 「마스터교원의 지속적 전문성 개발」의 흐름(물길 0~5)에 따라 진행하는 참여형 연수 웹앱입니다.
연수생은 로그인 없이 **별명**으로 의견 6개를 내고, 강사는 진행을 이끌면서 결과를 실시간으로 봅니다.

| 의견 | 위치(PPT) | 형식 | 강사 화면 결과 |
|---|---|---|---|
| 1 | 5쪽 · 전문성 개발이 필요한 이유 | 서술 | 의견 카드 모음 |
| 2 | 24쪽 · 나의 역량 수준 | 레벨 + 강점·보완 역량(A~G) | 레벨 분포, 역량별 강점/보완 비교 |
| 3 | 30쪽 · 목표 레벨 | 레벨 | 현재 vs 목표 레벨, 평균 성장 목표 |
| 4 | 31쪽 · 단기 계획(6개월 이내) | 서술 | 의견 카드 모음 |
| 5 | 32쪽 · 장기 계획(1년 이상) | 서술 | 의견 카드 모음 |
| 6 | 33쪽 · AX 시대의 교사 전문성은 ___ 이다 | 빈칸 채우기 | 워드클라우드 |

---

## 1. 바로 체험해 보기 (설정 없이)

`config.js`의 `firebase: null` 상태로 `index.html`을 열면 **체험 모드**입니다.

- 같은 브라우저의 탭끼리만 저장·동기화됩니다(다른 기기와는 공유되지 않음).
- 강사 탭 비밀번호: `1234` (config.js의 `demoPassword`)
- 강사 화면의 **예시 데이터 넣기**로 차트가 채워진 모습을 볼 수 있어요.
- 탭 하나는 연수생, 다른 탭은 `#instructor`로 열어 진행 동기화를 확인해 보세요.

> 파일을 더블클릭해서 열면 일부 브라우저에서 동작이 제한될 수 있어요. 아래 3번처럼 Vercel에 올려서 확인하는 게 가장 정확합니다.

## 2. Firebase 연결 (실제 연수용, 약 10분)

1. **프로젝트 만들기** — https://console.firebase.google.com 에서 프로젝트 추가 (Google 애널리틱스는 꺼도 됨)
2. **웹 앱 추가** — 프로젝트 개요의 `</>` 아이콘 → 앱 이름 입력 → 화면에 나오는 `firebaseConfig = { ... }`의 중괄호 부분을 복사 → `config.js`의 `firebase: null`의 `null` 자리에 붙여넣기
   ```js
   firebase: {
     apiKey: "AIza...",
     authDomain: "내프로젝트.firebaseapp.com",
     projectId: "내프로젝트",
     storageBucket: "...",
     messagingSenderId: "...",
     appId: "..."
   },
   ```
3. **로그인 방법 켜기** — 빌드 > Authentication > 시작하기 > 로그인 방법 탭
   - **익명** → 사용 설정 (연수생용: 로그인 화면 없이 자동 접속, 화면에는 별명이 표시됨)
   - **이메일/비밀번호** → 사용 설정 (강사용)
4. **강사 계정 만들기** — Authentication > 사용자 탭 > 사용자 추가 → 이메일·비밀번호 입력
   - 강사 화면에서 이 **이메일과 비밀번호**로 입장합니다.
   - `config.js`의 `instructorEmail`에도 같은 이메일을 적어 두면 이메일 칸이 미리 채워져요(선택).
5. **데이터베이스 만들기** — 왼쪽 메뉴 Firestore > 데이터베이스 만들기(Create database)
   - 위치: `asia-northeast3 (서울)` 권장 · 프로덕션 모드로 시작
6. **보안 규칙 넣기** — Firestore > 규칙 탭에 `firestore.rules` 내용을 통째로 붙여넣고,
   `teacher@example.com`을 4번의 강사 이메일로 바꾼 뒤 **게시**

규칙 요약: 연수생은 자기 의견만 쓰고 고칠 수 있고(마감된 활동은 불가), 진행 상태 변경·의견 삭제는 강사 계정만 할 수 있어요.

## 3. 배포 (Vercel)

**처음 올리기 — Vercel Drop**
1. https://vercel.com 에서 무료(Hobby) 계정 만들기 (GitHub 계정으로 가입 가능)
2. https://vercel.com/drop 에 접속
3. 이 폴더(`index.html`이 맨 위에 있는 폴더)나 그 폴더를 압축한 zip을 끌어다 놓기
4. 팀 선택 → 프로젝트 이름 입력(주소가 됨, 예: `aiedap-module5`) → **Deploy**
5. 생성된 `https://프로젝트이름.vercel.app` 이 연수 주소입니다.

> 로그인 없이 올리면 임시 주소라 시간이 지나면 사라져요. 꼭 로그인한 상태로 올리거나, 완료 화면의 **Claim your project**를 누르세요.

**고친 뒤 다시 올리기**
- Vercel 대시보드에서 해당 프로젝트를 열고 폴더를 프로젝트 화면에 끌어다 놓으면 새 버전으로 바뀌어요.
- vercel.com/drop 에 다시 올리면 **새 프로젝트(새 주소)**가 생기니 주의하세요.
- GitHub 저장소에 올려 두고 Vercel에서 Import 하면, 이후 push 할 때마다 자동 배포돼요.

## 4. 연수 당일 진행

1. 강사 PC에서 **👨‍🏫 강사** 탭 → 강사 계정 이메일·비밀번호 입력
2. **차수 코드** 정하기 — 차수마다 다른 코드(예: `gn-1104`)를 쓰면 응답이 섞이지 않아요. 바꾼 뒤 QR을 다시 띄우세요.
3. **📱 참여 QR 띄우기** → 화면에 띄우면 선생님들이 휴대폰으로 접속(PPT 5쪽의 Mentimeter QR 대신 사용)
4. 왼쪽 **진행** 목록
   - **○ 버튼** → 연수생 화면이 그 위치로 이동하고 “지금 진행 중” 표시가 나타남 (한 번 더 누르면 해제)
   - **스위치** → 활동 열기/마감
   - **연수생 화면 따라오기**를 끄면 자동 이동 없이 아래쪽 알림만 떠요.
   - **연수생에게 다른 의견 공개**를 끄면 연수생은 자기 의견만 보고, 결과는 강사 화면에서만 공개돼요.
5. 오른쪽 결과에서 **🖥 크게 보기** → 프로젝터용 큰 화면 (← → 로 의견 이동, Esc로 닫기)
6. 부적절한 의견은 카드의 **삭제**로 지울 수 있어요.
7. 끝나면 **⬇ CSV 내려받기** — 참여자별 한 줄로 6개 의견이 정리됩니다(엑셀에서 바로 열림).

## 5. 알아 두면 좋은 점

- **별명**: 처음 접속하면 별명을 정해요(실명은 받지 않음, 차수 안에서 중복 불가). 위쪽 🙂 별명 버튼으로 언제든 바꿀 수 있고, 바꾸면 이미 낸 의견에도 새 별명이 표시돼요. CSV에는 참여자 번호와 별명이 함께 나옵니다.
- **규칙 다시 게시**: 별명 기능 때문에 `firestore.rules`에 people 규칙이 추가됐어요. 새 규칙을 Firestore > 규칙에 다시 붙여 넣고(강사 이메일 수정) 게시해 주세요.
- **수정**: 연수생은 같은 의견을 다시 보내 고칠 수 있어요(1인 1응답).
- **무료 사용량**: Firebase 무료(Spark) 요금제는 하루 읽기 5만 회입니다. 50명 규모 연수 한 차수에 대략 2만 회 안팎이 쓰여 하루 2차수 정도는 무료로 충분해요. 더 많이 운영하면 Firebase 콘솔의 사용량 탭을 확인하세요.
- **만족도 조사 주소**: PPT 35쪽의 `숏.한국/아이에답/`를 `https://숏.한국/아이에답/`로 연결해 두었어요. 실제 주소가 다르면 `config.js`의 `satisfaction`을 고쳐 주세요.
- **로그인 오류**: 강사 로그인 시 `auth/unauthorized-domain` 오류가 나오면 Authentication > 설정 > 승인된 도메인에 Vercel 주소(○○○.vercel.app)를 추가하세요.

## 6. 파일 구성

```
index.html       화면 구성과 디자인
app.js           동작(의견 저장, 진행 동기화, 차트, CSV)
config.js        ← 설정은 이 파일만 고치면 됩니다
firestore.rules  Firebase 보안 규칙
assets/          로고, 마스코트, 레벨 배지, PPT 이미지, QR 생성 라이브러리
```
